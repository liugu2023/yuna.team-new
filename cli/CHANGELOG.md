# 更新记录

## 0.2.0

### 文章列表与阅读

- 文章编号对应本站最近一次 `posts` 列表；筛选结果和后续新增文章不会改变已显示编号的含义。
- `read --tag / --kind` 可显式查询当前筛选结果；纯数字 slug 使用 `--slug`。
- `-n` 支持跨页取数，`--all` 和标签筛选不再受 500 篇上限影响。
- `read --web --json` 只输出地址，不启动浏览器。

### 与网站保持一致

- `join` 感知招新状态，结束后显示收官与咨询入口，收起报名流程和旧报名链接。
- 课表保留站内附件、邮件和无标题链接，届次按数字自然排序。
- 修复联系邮箱地址的解析，增加 `open recap` 入口。

### 终端与网络

- 改善英文、长词、中英混排、ANSI 颜色、标题和引用的折行；非法 HTML 实体不再导致阅读失败。
- 浏览器启动按实际退出结果报告成功或失败，Windows 地址作为参数处理。
- 直连的连接超时或不可达可静默重试一次，给予每个地址 1000ms 的连接尝试时间；重试仍受原有总超时约束。
- 显式代理失败不退回直连；错误信息保留嵌套连接错误，空代理和无效参数会明确报错。

### 打包与验证

- 打包前自动编译，并检查实际 npm 包的必要文件和排除项。
- 新增 40 项回归测试，覆盖命令、分页、缓存、终端和网络行为。
- CI 增加 Windows / Linux、Node 22 / 24 与最低 Node 18.17 检查。
- 修复手动触发时二进制构建被跳过；手动构建只保留产物，tag 推送触发 npm 与 GitHub Release 发布。

### 使用变化

- 首次按编号阅读前先运行 `yuna posts`。编号按站点分别缓存；直接使用 slug 不依赖缓存。
- 缓存默认位于 Windows 的 `%LOCALAPPDATA%/yuna-team`，或 Linux/macOS 的 `$XDG_CACHE_HOME/yuna-team`（未设置时为 `~/.cache/yuna-team`），可用 `YUNA_CACHE_DIR` 指定。
- `join --json` 保留原字段，新增 `closed`、`recruitmentStatus`、`stats` 和 `recapUrl`；结束态的 `kpi`、`steps` 为空数组。
- 无关命令选项、多余位置参数，以及 `posts --all` 与 `-n` 同时使用，均返回用法错误。
